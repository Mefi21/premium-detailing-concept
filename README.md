# Premium Detailing Concept

A polished concept/demo website for a premium automotive detailing studio.

## Demo

https://premium-detailing-concept.netlify.app/

## About

The project explores how a detailing studio can present a broad service catalog through a premium, image-led landing page while keeping price discovery and lead capture easy to use.

## Features

- Responsive single-page layout
- Filterable detailing service cards
- Interactive price calculator
- Expandable service catalog
- Gallery lightbox
- Reviews and package comparison sections
- Demo lead form stored only in the browser with `localStorage`
- Accessible controls and mobile navigation

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Static image assets

## Architecture

`index.html` contains the page structure and service content, `style.css` defines the responsive visual system, and `script.js` provides filtering, calculator, modal, navigation, and demo-form behavior. The project has no backend or build step and can be deployed directly to a static host.

## My role

I created the concept, responsive interface, page structure, visual system, service interactions, calculator, gallery behavior, and front-end-only lead experience.
